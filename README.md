# EMBERHOLD

EMBERHOLD is an original lantern defense game about holding a forest glade against the shadows. Your lantern fires on its own; gather the ember shards defeated shadows leave behind, choose upgrades as you level up, and survive for as long as you can.

## How to play

Move with WASD or the arrow keys. The lantern automatically targets nearby shadows. Collect the glowing shards to fill the XP bar and select an upgrade when you level up. P or Esc pauses, M toggles sound, and Space or click starts or restarts. Score is kills plus time survived.

## Run it

Serve the `game/` directory with any static server and open `index.html`. Add `?seed=N` for a repeatable run, or `?shot=start|play|levelup|end` to stage a screenshot scene.
